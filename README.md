# Sangi Hospital - IPD Registration System

A React-based IPD (In-Patient Department) Registration frontend for Sangi Hospital.

## Tech Stack
- React 18
- Vite
- JavaScript (JSX)

## Getting Started

### Installation
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.
